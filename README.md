# Night Bloom — unsolicited poster concept

Independent sample for a [public one-off techno poster request](https://www.reddit.com/r/DesignJobs/comments/1ww4ed1/hiring_techno_party_poster/). This is **not** a commissioned design, customer work, or the event's actual identity.

- `poster.svg`: editable vector source, grouped by paper texture, shapes, headline, event details, lineup and footer. Lineup, event name, date and venue are placeholder live text.
- `poster.png`: visual preview.
- Canvas: 1080 × 1350 px. Experimental typography, photocopy texture and acid color respond to the brief. Shapes and text can be imported into Figma or another vector editor, subject to font substitution.

The sample does not reuse imagery from the buyer's Pinterest board. It was created with AI assistance and manually checked; disclose that when proposing it. Before paid work, confirm the buyer allows this workflow, final format, exact event copy and revision scope.
